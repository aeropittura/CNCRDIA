# Brain

Malicious three-party replicated secret sharing over Z_2^k with
triples generated by the DOS18 approach (single preprocessing) as
described by Eerikson et al., "Use your Brain!"
(https://eprint.iacr.org/2019/164). Launcher: `brain.sh`.

## Main classes

- `BrainShare`: share type.
- `BrainPrep`: triple generation and checking.

Headers declare, `.hpp` files hold the template definitions.
See `docs/navigating-c++.rst` for how the pieces fit together.
